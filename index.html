Let's start what is PC

PC stands for Personal Computer. It refers to a multi-purpose computer whose size, capabilities, and price make it suitable for individual use.

PC's parts is

built from several core hardware components that work together to process data, render graphics, and run software

Learn more

In PC we have

CPU: The brain that processes commands. Motherboard: The main board connecting all components. RAM: Fast, temporary memory for open apps. GPU: Handles graphics and visual output. Storage (SSD/HDD): Saves files, software, and the OS permanently. Power Supply (PSU): Supplies power to all parts. Cooler & Fans: Keeps components from overheating. Case: Houses and protects the hardware.
